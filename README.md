# **Decodelabs Data Science Internship Project**

### **Description:**

This project contains the completion of five fundamental data science tasks assigned during the Decodelabs internship. 

Using a movie metadata dataset (mymoviedb), this project demonstrates the end-to-end data science workflow. 

It includes data collection, data cleaning (handling missing values and duplicates), exploratory data analysis (EDA) to find statistical trends, data visualization using Matplotlib and Seaborn, and the creation of a basic predictive Linear Regression model to analyze the relationship between a movie's popularity, vote count, and its average rating.

This project was developed using a Python Notebook on Google Colab. 

### **To run and test the code:**

**1.** Open Google Colab or your local Jupyter Notebook environment.

**2.** Upload the Python Notebook file (.ipynb) and ensure the dataset file (mymoviedb (1).csv) is uploaded to the same working directory.

**3.** If using Colab, you can upload the dataset directly to the session storage via the folder icon on the left sidebar.

**4.** Run the notebook cells sequentially (or select "Run All") to execute the code, view the data processing steps, generate the visualizations, and see the model predictions.
